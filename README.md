Nome do projeto: 
Vinheria Agnello

Descrição do Projeto: 
Aplicação web para gerenciamento básico do estoque de vinhos da Vinheria Agnello. O usuário cadastra informações do vinho (nome, tipo, safra e quantidade) através de janelas de interação, e os dados são organizados e exibidos no console do navegador.
